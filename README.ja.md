# linesvg-svg-line-art-examples

`linesvg-svg-line-art-examples` は、編集可能な SVG 線画サンプル集、外部依存ゼロのコマンドライン一括スタイル変更ツール、および実践的な SVG 編集ガイドをまとめたオープンソースリポジトリです。デザイナー、フロントエンド開発者、ならびにレーザーカッター、カッティングマシン、ペンプロッター、印刷用ぬり絵を扱うメイカー向けに構成されており、ラスター画像と SVG の実例ペアの確認、手元の SVG ファイルに対する線幅・色・塗りの一括変更、制作前のベクター形状チェックを行えます。本リポジトリのサンプル SVG は LineSVG で作成されており、LineSVG の公式サイトは [https://linesvg.ai](https://linesvg.ai) です。

## クイックスタート：SVG の線幅と色を一括変更する

[`tools/svg_restyle.py`](./tools/svg_restyle.py) は Python 3 の標準ライブラリ（`xml.etree.ElementTree`）のみを使用しており、`pip install` は不要です。Illustrator、Inkscape、Figma、各種ベクタートレースツールから書き出された有効な `.svg` ファイルに対応し、プレゼンテーション属性（`stroke="..."`）とインライン CSS（`style="stroke:..."`）の両方を更新し、`viewBox` を維持しつつ、デフォルトでは線のないアクセント塗り要素をそのまま保護します。

```bash
# 1. Thicken outlines on a single coloring page and set fill="none"
python3 tools/svg_restyle.py examples/coloring-page.svg examples/restyled/ \
  --stroke-width 4 --stroke "#111827" --fill none

# 2. Recolor and resize strokes on a mixed stroke+fill botanical illustration
#    (solid berry fills without strokes are preserved automatically)
python3 tools/svg_restyle.py examples/botanical.svg examples/restyled/ \
  --stroke-width 2.5 --stroke "#1e3a5f"

# 3. Scale existing stroke widths by 1.5x across an entire directory of SVGs
python3 tools/svg_restyle.py examples/ ./out-scaled/ \
  --stroke-scale 1.5 --stroke "#334155"
```

すべてのフラグ（塗りのみのシルエットを線画アウトラインへ変換する `--all-shapes` や、ディレクトリを再帰処理する `-r` を含む）については [`tools/README.md`](./tools/README.md) を参照してください。

## SVG 線画サンプル（`examples/`）

[`examples/`](./examples/) フォルダには、代表的な 3 種類のベクター構造にわたる 16 個の SVG ファイルと、入力画像 → 出力 SVG の対になった 3 組のサンプルが含まれています。

- **純粋な中心線ストローク（`fill="none"`）**：
  - [`examples/coloring-page.svg`](./examples/coloring-page.svg) — 閉じた輪郭で構成された印刷用ぬり絵（`<path>` 要素数 `138`）
  - [`examples/single-line.svg`](./examples/single-line.svg) — 二重線のない開いたシングルラインのリース、Cricut の Draw・Foil・Score 向け（`<path>` 要素数 `115`）
  - [`examples/face-oneline.svg`](./examples/face-oneline.svg) — プロッターや刺繍向けの連続したミニマルな一筆書きポートレート（`<path>` 要素数 `12`）
  - [`examples/icon-coffee.svg`](./examples/icon-coffee.svg) — 線幅を統一したアウトラインアイコン（`<path>` 要素数 `17`）
- **ストローク＋ベタ塗りのアクセント**：
  - [`examples/botanical.svg`](./examples/botanical.svg)、[`examples/lighthouse.svg`](./examples/lighthouse.svg)、[`examples/bicycle.svg`](./examples/bicycle.svg)、[`examples/hero-camera.svg`](./examples/hero-camera.svg)、[`examples/tattoo.svg`](./examples/tattoo.svg)
- **閉じた塗りのシルエット（`stroke` なし）**：
  - [`examples/laser-cut.svg`](./examples/laser-cut.svg) — パーツが連結されたカット用オーナメント（`<path>` 要素数 `2`）
  - [`examples/logo-mountain.svg`](./examples/logo-mountain.svg) — 拡大縮小可能なベクターロゴマーク（`<path>` 要素数 `2`）
- **ラスター入力画像 → ベクター SVG 出力のペア**：
  - [`examples/cat-photo.jpg`](./examples/cat-photo.jpg) → [`examples/cat-lines.svg`](./examples/cat-lines.svg)（カメラ写真を編集可能な線画へ変換）
  - [`examples/sketch-input.jpg`](./examples/sketch-input.jpg) → [`examples/sketch-lines.svg`](./examples/sketch-lines.svg)（手描きの鉛筆スケッチをクリーンなストロークへ変換）
  - [`examples/cover-input.png`](./examples/cover-input.png) → [`examples/cover-vectorize.svg`](./examples/cover-vectorize.svg)（ラスターの葉イラストをストロークと塗りへトレース）

各ファイルのバイトサイズ、`<path>` 要素数、およびスタイル変更済みサンプルの一覧は [`examples/README.md`](./examples/README.md) に記載されています。

## ガイド：SVG 線画の構造理解と編集

以下の要点をまとめたリファレンスとして、[`docs/editing-svg-line-art.en.md`](./docs/editing-svg-line-art.en.md)（または中国語版の [`docs/editing-svg-line-art.md`](./docs/editing-svg-line-art.md)）をご覧ください。

1. **SVG の基本構造**：`viewBox` が見た目の `stroke-width` を決める仕組み、開いた `<path>` と閉じた `<path>` のコマンドの違い、`fill="none"` を省略すると開いた曲線が黒い楔形になってしまう理由。
2. **中心線ストロークと塗り輪郭の違い**：トレースされた一部の SVG がペンプロッターで二重線として描画されたり `stroke-width` で細くできなかったりする理由と、テキストエディタやベクターエディタでの見分け方。
3. **コード上での編集**：インライン `style="..."`、`<style>` クラス、プレゼンテーション属性、`<g>` グループ間の CSS 詳細度（specificity）、および `currentColor` と `vector-effect="non-scaling-stroke"` の使い方。
4. **用途別制作チェックリスト**：レーザーカッター・カッティングマシン、Cricut・ペンプロッター、印刷用ぬり絵、刺繍ワークフロー、サーマルタトゥーステンシル向けに SVG を準備する際の確認事項。

## 自動化したい場合

テキストプロンプトから編集可能な SVG 線画を生成したり、写真やスケッチを自動変換したりしたい場合は、[LineSVG](https://linesvg.ai) を利用できます。テキスト記述、またはアップロードした PNG、JPG、WebP 画像（最大 20 MB）から、編集可能なライン、カット用シェイプ、カラーレイヤーの 3 つの出力構造で SVG を生成でき、一筆書き、ぬり絵、タトゥーステンシル、Cricut 用シングルラインファイル、レーザーカットなどの用途に対応しています。さらに、SVG・PNG エクスポートに対応したオンライン SVG エディタ（最大 2 MB までの SVG アップロードに対応）も備えています。サインインなしでワークベンチのデモを試すことができ、新規アカウント登録時には 30 日間有効なウェルカムクレジット 10 クレジットが付与されます（生成、変換、AI 編集のデフォルト消費量は 1 回あたり 10 クレジットです）。

- 公式サイト：[https://linesvg.ai](https://linesvg.ai)
- 関連ガイド：[Photo to Line Art Software Comparison](https://linesvg.ai/blog/photo-to-line-art-software-comparison) · [AI Tools for Editable SVG Line Art](https://linesvg.ai/blog/ai-editable-svg-line-art-tools)
